# ABG Tool – Version 2 (Foundation)

## ✅ Features
- ABG interpretation (Acidosis / Alkalosis)
- Primary disorder detection
- Compensation (Winter’s formula)
- Mixed disorder detection
- Ventilator context (Mode, RR, TV, PEEP, FiO2)
- Ventilator suggestions (basic logic)
- Risk flag system

## ⚠️ Limitations
- Oxygenation logic basic
- No P/F ratio
- No RSBI
- No prioritization logic

## 📌 Notes
- Suggestions are rule-based (not AI)
- Designed for educational / clinical support only
- Requires clinical correlation

- Add P/F ratio
- Improve oxygenation logic
- Add RSBI (weaning module)
